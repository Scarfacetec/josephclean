# Joseph Clean

Site de higienização de estofados em Fortaleza.

## Cloudflare Pages

Importe Scarfacetec/josephclean em Workers & Pages → Pages.

- Nome: josephclean
- Branch: main
- Framework: None
- Build: npm run build
- Diretório de saída: dist

Endereço previsto: https://josephclean.pages.dev (depende da disponibilidade no Cloudflare). Para outro endereço ou domínio próprio, configure SITE_URL com a origem HTTPS e faça novo deploy. O build atualiza canonical, Open Graph, robots e sitemap.

## WhatsApp

Prévia Open Graph com imagem JPEG 1200 × 630 em /og-image.jpg. Depende da publicação e do cache do WhatsApp. Compartilhe a URL final após o deploy para conferir.

## Local

Execute npm run build e sirva dist por HTTP. Não há dependências npm. Arquivos de referência e vídeo original são ignorados no Git.
